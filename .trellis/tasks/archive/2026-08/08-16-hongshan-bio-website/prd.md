# 宏杉生物独立官网

## Goal

交付一个可直接双击打开、无需构建工具和后端服务的宏杉生物企业官网单文件，体现现代生物科技企业的专业、可信与克制质感。

## Requirements

* 仅交付一个独立 HTML 文件，CSS 与 JavaScript 全部内联。
* 网站使用中文，并包含适量英文品牌辅助文案。
* 页面包含导航、首屏、核心能力、技术平台、质量理念、合作流程、联系入口和页脚。
* 使用冷灰、深绿和荧光黄绿色作为统一视觉体系，避免常见紫色科技渐变。
* 视觉资产嵌入 HTML，保证文件离线打开时仍完整显示。
* 适配桌面端和移动端，支持键盘导航与减少动态效果偏好。
* 所有业务数据与联系方式保持为可替换展示内容，不虚构具体资质、地址或客户案例。

## Acceptance Criteria

* [ ] 双击 HTML 文件即可完整访问，不依赖 npm、CDN 或外部字体。
* [ ] 360px 手机宽度下无横向溢出，导航可展开与关闭。
* [ ] 页面锚点、咨询按钮、联系表单交互均可用。
* [ ] 表单明确提示当前为静态演示，不会提交或收集信息。
* [ ] 图片有替代文本，焦点状态清晰，支持 prefers-reduced-motion。
* [ ] HTML、CSS 与 JavaScript 通过基础静态检查。

## Definition of Done

* 独立 HTML 文件已生成并完成桌面/移动渲染检查。
* 页面不存在外部运行时依赖。
* 交付路径与可替换内容已说明。

## Technical Approach

使用语义化 HTML、内联 CSS 和少量原生 JavaScript。视觉图片先生成，再转为 data URI 内嵌进单文件。交互仅包含移动导航、滚动显隐和静态表单反馈。

## Decision (ADR-lite)

**Context**: 用户明确要求独立项目与单份 HTML。

**Decision**: 不接入现有 Vue/Vite 应用，也不引入第三方库；交付一个自包含的 `hongshan-bio.html`。

**Consequences**: 文件可直接预览与迁移，但联系表单只做前端演示，正式上线时需替换实际联系方式并接入提交接口。

## Out of Scope

* 内容管理后台、数据库与表单邮件服务。
* 未经确认的专利、资质、融资、客户、团队成员与经营数据。
* 多语言路由与搜索引擎站点地图。

## Technical Notes

* 本文件与现有 market-shop 业务代码隔离。
* 设计方向：现代 B2B 生物科技，冷静理性、科研质感、非模板化营销页面。
* 设计参数：DESIGN_VARIANCE 7 / MOTION_INTENSITY 4 / VISUAL_DENSITY 4。
