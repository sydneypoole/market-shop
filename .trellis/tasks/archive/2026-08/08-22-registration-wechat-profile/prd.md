# 注册时保存微信头像与昵称

## 目标

会员通过邀请码注册或发起人认领时，在注册页使用微信小程序原生昵称和头像能力完成资料选择；账号创建后立即保存昵称并上传头像，全部成功后再进入商城。

## 实现范围

- 注册页增加隐私指引确认。
- 使用 `input type="nickname"` 获取微信昵称。
- 使用 `button open-type="chooseAvatar"` 获取微信头像临时文件。
- 注册前要求昵称、头像和隐私授权均有效。
- 微信登录码仍只用于一次注册请求，不持久化、不重放。
- 注册成功取得会员令牌后，依次调用昵称更新接口和头像上传接口。
- 头像上传失败时保留当前认证会话和临时头像，重试仅上传头像，不重复注册或重复保存昵称。
- 昵称保存失败时保留已创建账号状态，允许修改昵称并重试资料保存，不重复调用 `wx.login`。
- 不调用已废弃的 `wx.getUserProfile` / `wx.getUserInfo`，不索取手机号。

## 验收标准

1. 未同意隐私指引、未选择头像或昵称为空时，不调用 `wx.login`。
2. 正常流程只获取一次微信登录码、只创建一次账号、只保存一次昵称和头像。
3. 资料保存完成前不跳转商城。
4. 头像上传失败后的重试不重复注册，也不重复保存已成功的昵称。
5. 邀请码、scene 和发起人认领模式继续保持原有契约。
6. 小程序全部测试及 `git diff --check` 通过。
