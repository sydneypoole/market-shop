# 优化宏杉生物官网视觉

## Goal

在保留现有宏杉生物品牌色、中文内容、信息架构与单文件交付方式的前提下，依据 design-taste-frontend 规范优化视觉层级、页面节奏、主题一致性、动效性能与可访问性。

## Existing Design Audit

* 品牌资产：冷灰底、深绿色、单一荧光黄绿色强调色，HS 几何字标，四张已生成科研摄影。
* 信息架构：首屏、核心能力、技术平台、质量理念、合作流程、联系入口；锚点与导航标签保持稳定。
* 当前亮点：首屏分屏构图、生成式科研图片、自包含资源、移动导航和静态表单均已完成。
* 需要改进：页面存在多次浅色/深色主题反转，多个分栏标题重复，首屏底部装饰信息条、图片叠加标签、泛化步骤编号以及滚动事件监听不符合技能规范。
* 当前设计参数：DESIGN_VARIANCE 7 / MOTION_INTENSITY 4 / VISUAL_DENSITY 4。
* 优化参数：DESIGN_VARIANCE 7 / MOTION_INTENSITY 5 / VISUAL_DENSITY 4。

## Requirements

* 保持 `hongshan-bio.html` 为单文件，不引入第三方运行时依赖。
* 保留导航锚点、表单字段名称、品牌字标、品牌色与四张科研图片。
* 页脚展示“粤ICP备2026115782号-1”，并链接到工信部备案查询页面。
* 将正文锁定为统一浅色主题，仅在最终联系区进行一次有意的深色转换；同时通过系统偏好提供完整深色模式。
* 删除首屏装饰信息条与图片叠加标签，把必要内容移到独立内容区。
* 将分栏式小段落标题改为垂直堆叠，减少模板化节奏。
* 删除无功能的数字、泛化 STEP 标签、装饰色点和误导性箭头。
* 统一联系类 CTA 文案，优化按钮按压反馈与表单文字对比度。
* 用 IntersectionObserver 替代逐帧滚动事件监听，保留动效并支持 reduced motion。
* 调整导航高度、首屏上边距和标题尺度，保证桌面与移动首屏 CTA 均在初始视口内。

## Acceptance Criteria

* [x] 页面无 em dash 与 en dash，无外部网络资源。
* [x] 主题反转仅发生在最终联系区，深色模式下全页视觉层级完整。
* [x] 页面代码不存在 `window.addEventListener('scroll')`。
* [x] 首屏仅保留 eyebrow、标题、说明和 CTA 四组文本。
* [x] 桌面导航单行且高度不超过 80px。
* [x] 360px 宽度无横向溢出，移动导航与表单交互可用。
* [x] 图片无叠加标签，尺寸声明正确且资源均内嵌。
* [x] 页脚备案号可见、可点击，链接安全属性完整。
* [x] 联系表单标签、占位符、状态与按钮在深色背景上清晰可读。
* [x] JavaScript 语法检查和浏览器渲染检查通过。

## Technical Approach

直接优化原生 HTML/CSS/JavaScript：新增语义化能力条，将正文各区统一到语义色彩 token；增加 prefers-color-scheme 深色 token；使用两个 IntersectionObserver 分别处理页眉状态和内容显隐；保留单文件数据 URI 图片。

## Decision (ADR-lite)

**Context**: 当前页面结构与品牌方向有效，问题集中在视觉规范和局部实现。

**Decision**: 采用保留式优化而非推倒重做，维持现有信息架构与内容，只调整组合方式、主题 token、动效机制和细节文案。

**Consequences**: 风险较低，现有链接和表单字段保持兼容；页面仍可离线直接打开。

## Out of Scope

* 更换公司名称、Logo、真实联系方式或业务资质内容。
* 引入框架、构建工具、后端接口或分析埋点。
* 改变现有锚点 ID 和表单字段顺序。
